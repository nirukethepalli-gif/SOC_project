# System-on-Chip Test Cases & Verification Plan

**Project:** RISC-V Based SoC for Lightweight Neural Network Inference Acceleration  
**Processor Core:** CHIPS Alliance VeeR EL2 (RV32IMC)  
**Custom Accelerators:** Matrix Multiplier IP, Activation Unit IP, DMA Controller IP  
**Target Simulator:** Synopsys VCS (cs -full64 -sverilog)

---

## 1. Test Verification Strategy & Classification

To ensure complete verification coverage for the Honours Project, test cases are strictly classified into two categories:

1. **Internal Testcases (Unit-Level / IP-Level Verification):**  
   Target individual custom IPs and hardware sub-modules in isolation (without running CPU firmware). These verify fixed-point arithmetic precision, saturation, piecewise-linear approximation accuracy, buffer auto-indexing, AXI4 master burst state machines, and error handling.
2. **External Testcases (System-Level / SoC Integration Verification):**  
   Target the full integrated System-on-Chip (soc_top.sv) with the VeeR-EL2 RISC-V CPU executing bare-metal C/assembly firmware. These verify end-to-end neural network inference ( = \text{ReLU}(W \cdot X + B)$), autonomous DMA transfers across Data Memory, peripheral MMIO register decoding, UART console output, and GPIO status flags.
